# INVC Barcode Workspace

หน้าเว็บ HTTPS สำหรับทีมงานสแกน Barcode ร่วมกันหลายอุปกรณ์ โดยเก็บสถานะงานไว้ใน Supabase และส่งไฟล์ผลลัพธ์กลับเข้าเว็บ INVC เดิมเพื่อตรวจสอบก่อนอัปเดต SQL Server

## ขั้นตอนใช้งาน

1. ผู้ดูแลสร้างบัญชีผู้ใช้ใน Supabase Auth และเปิดสิทธิ์ Barcode ให้บัญชีนั้น
2. ผู้มีสิทธิ์นำเข้า นำไฟล์งาน `invc-barcode-work/v1` จากระบบ INVC เข้าระบบหนึ่งครั้ง
3. ทุกอุปกรณ์เข้าสู่ระบบด้วยบัญชีที่ผู้ดูแลสร้างให้ และทำงานกับชุดข้อมูลกลางเดียวกัน
4. ผลสแกนซิงก์ระหว่างอุปกรณ์แบบ Realtime
5. ผู้มีสิทธิ์ส่งออกดาวน์โหลดไฟล์ผลลัพธ์ แล้วนำกลับไปตรวจสอบในระบบ INVC ก่อนเขียน SQL Server

หน้าเว็บไม่มีระบบสมัครสมาชิก ผู้ใช้ไม่สามารถสร้างบัญชีเองได้จากหน้าเว็บ

## หลักความปลอดภัย

- ไม่มี connection string, SQL credential หรือ API ภายในอยู่ใน repository
- ใช้ Supabase Auth และ Row Level Security; ผู้ไม่เข้าสู่ระบบอ่านหรือบันทึกข้อมูลไม่ได้
- บันทึก Barcode ผ่าน RPC ที่ตรวจสิทธิ์ รูปแบบ/check digit ค่าปัจจุบัน และข้อมูลซ้ำก่อนเขียน
- ภาพจากกล้องประมวลผลในอุปกรณ์ด้วย BarcodeDetector หรือ ZXing
- ไม่อัปโหลดภาพจากกล้องขึ้นฐานข้อมูล
- ส่งออกเฉพาะรายการที่ทีมงานเพิ่ม Barcode ในชุดงานนั้น
- การตรวจซ้ำและเขียน SQL ต้องเกิดในเว็บ INVC ภายในองค์กร

## ทดสอบ

1. เปิดเว็บผ่าน HTTPS
2. เข้าสู่ระบบด้วยบัญชีที่ผู้ดูแลสร้างให้
3. เลือกชุดงาน หรือให้ผู้มีสิทธิ์กด `นำเข้าไฟล์งาน`
4. เปิดการ์ดรายการที่ยังไม่ผูก แล้วสแกนหรือกรอก Barcode ที่ check digit ถูกต้อง
5. เมื่อทำครบ ให้ผู้มีสิทธิ์กด `ส่งออกผล`
